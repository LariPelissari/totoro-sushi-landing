# 🍣 Totoro Sushi - Premium Experience

![Totoro Sushi Banner](https://images.unsplash.com/photo-1579871494447-9811cf80d66c?q=80&w=1200&auto=format&fit=crop)

> Landing page profissional e responsiva desenvolvida para um restaurante japonês premium (Omakase), com foco em alta conversão e sofisticação visual.

🌐 **Live Demo:** [Totoro Sushi Experience](https://totoro-sushi-landing.lovable.app/)

## 🍱 Sobre o Projeto
Este projeto foi concebido para transmitir a essência do *Wabi-Sabi* (beleza na simplicidade) e do *Omotenashi* (hospitalidade japonesa). O design utiliza uma paleta de cores escura (preto e carvão) com acentos em dourado, criando uma atmosfera exclusiva que guia o visitante desde a descoberta visual até a reserva.

## ✨ Principais Funcionalidades
- **Hero Section Imersiva:** Apresentação de alto impacto com efeito parallax sutil e *Call to Action* claro.
- **Destaques do Menu:** Exibição elegante dos pratos assinatura do chef.
- **Prova Social:** Seção dedicada a depoimentos para gerar autoridade e confiança.
- **Design Responsivo:** Experiência fluida e otimizada para dispositivos móveis, tablets e desktops.
- **Conversão Direta:** Integração com botão flutuante do WhatsApp para agilidade nas reservas e atendimento.

## 🛠️ Tecnologias Utilizadas
O projeto foi construído e estruturado utilizando componentes modernos de desenvolvimento web (gerado via Lovable):
- **React** 
- **TypeScript**
- **Vite**
- **Tailwind CSS** (para estilização rápida e responsiva)
- **Lucide Icons**
